## Why this module

The below-the-prompt track built the transformer's parts one at a time — tokens, attention, the KV cache, rotary position, sampling. This module assembles them into a working whole: a complete forward pass from token ids to a next-token distribution, small enough to run in your head and real enough that every number is computed, not asserted. The payoff of seeing the whole pass at once is that the parts stop being separate tricks and become one pipeline with a clear shape, and that shape makes visible the single design decision that separates a language model from a machine that memorizes: the causal mask. We build the pass, watch a token become a prediction, and then prove — by a broken invariance, not by assertion — exactly what the mask forbids and why a model without it is silently, fatally broken.

The forward pass is a sequence of transforms on a stream of vectors. Each token becomes an embedding vector; attention lets each position gather information from other positions, weighted by a query-key match, with rotary position mixed in so the match depends on relative distance; a residual connection adds the attention output back to the input so the original signal is never lost; LayerNorm standardizes the result; an MLP transforms each position independently; another residual and norm; and finally a projection to vocabulary logits, softmaxed into a distribution. Every one of those is a few lines of arithmetic, and the module shows each running on real vectors. Then the causal mask: a language model predicts token i+1 from tokens 1 through i, so position i must never attend to positions after it. The consequence of getting this wrong is not a small error — it is a model that reads the answer during training, achieves a deceptively low loss, and then produces nonsense at generation time, because the future tokens it learned to lean on are exactly the ones that do not exist yet when you actually run it.

You need the whole below-the-prompt track behind you: `tokens-basic-01` for what a token is, `attention-inter-01` for the query-key-value dot product, `rope-inter-01` for rotary position, and `sampling-inter-01` for the softmax at the end. Everything runs offline against a tiny weight fixture — vocab 6, d_model 4, one layer, one head — stdlib Python 3, `$0.00`. The weights are generated by a fixed formula, not trained, so the model is not good; the point is the wiring and the mask, both of which are exactly correct. The instinct to unlearn is that a transformer is an impenetrable stack. It is a short pipeline of small transforms, and once you have run each one on real numbers, the only deep part left is why the mask matters — which is the part this module proves.

## Concepts

Named here so you can find them again; each is built below.

- **Embedding** — the lookup that turns a token id into a d_model vector; the start of the residual stream.
- **Residual stream** — the running vector per position that each sublayer reads from and adds back to.
- **Scaled dot-product attention** — each position gathers a weighted sum of value vectors, weighted by query-key match over the square root of the dimension.
- **Causal mask** — forbidding a position from attending to later positions; what makes prediction honest.
- **LayerNorm** — standardizing a vector to zero mean and unit variance to stabilize the stream.
- **MLP** — a per-position two-layer network with a ReLU; the transformer's other half.
- **Weight-tied unembedding** — projecting the final vector to logits using the embedding matrix again.
- **Causality invariance** — the property that a position's prediction cannot change when future tokens are added.

### The building blocks: arithmetic, not magic

Before the pass, the primitives. A transformer is matrix-vector products, dot products, a sum, and a couple of nonlinearities — nothing heavier.

```
# tinygpt.py:43-63 — COMPLETE (the linear-algebra primitives)
def matvec(mat, vec):
    """mat is rows x cols (list of rows); vec is length cols. Returns length rows."""
    return [sum(m * v for m, v in zip(row, vec)) for row in mat]


def vecmat(vec, mat):
    """vec length R times mat (R x C) -> length C. (mat indexed [r][c].)"""
    cols = len(mat[0])
    return [sum(vec[r] * mat[r][c] for r in range(len(vec))) for c in range(cols)]


def add(a, b):
    return [x + y for x, y in zip(a, b)]


def dot(a, b):
    return sum(x * y for x, y in zip(a, b))


def relu(v):
    return [x if x > 0 else 0.0 for x in v]
```

That is the entire toolkit for the linear parts. `matvec` applies a weight matrix to a vector — that is what every projection (query, key, value, output, MLP layers) is. `dot` is the attention score and the final logit. `add` is the residual connection. `relu` is the MLP's nonlinearity. There is no operation in a transformer forward pass more exotic than these, repeated in a particular order.

### Softmax, LayerNorm, RoPE: the three shaping functions

Three functions shape the stream rather than transform it linearly. Softmax turns scores into a distribution; LayerNorm standardizes; RoPE rotates in position.

```
# tinygpt.py:68-91 — COMPLETE (softmax, layernorm, rope)
def softmax(xs):
    m = max(xs)
    exps = [math.exp(x - m) for x in xs]
    s = sum(exps)
    return [e / s for e in exps]


def layernorm(v):
    """Standardize to zero mean, unit variance (no learnable affine here)."""
    n = len(v)
    mean = sum(v) / n
    var = sum((x - mean) ** 2 for x in v) / n
    denom = math.sqrt(var + 1e-9)
    return [(x - mean) / denom for x in v]


def rope(vec, pos, theta):
    """Rotate successive 2D pairs of the vector by pos*theta (one frequency here)."""
    out = list(vec)
    for i in range(0, len(vec) - 1, 2):
        c, s = math.cos(pos * theta), math.sin(pos * theta)
        x, y = out[i], out[i + 1]
        out[i], out[i + 1] = x * c - y * s, x * s + y * c
    return out
```

Softmax you have seen in sampling; here it appears twice, once inside attention over positions and once at the end over the vocabulary. LayerNorm keeps the residual stream from drifting to large or tiny magnitudes as it passes through sublayers — it re-centers and re-scales each position's vector, which is what makes deep stacks trainable. RoPE rotates each pair of dimensions by an angle proportional to position, the mechanism from the rotary module, so attention scores depend on relative distance. Each is a shaping step: it changes the vector's distribution without being a learned linear map.

### Attention, with the mask in one line

Attention is the heart. Each position projects to a query, a key, and a value; the query of position i is matched against the key of every position j; the matches become weights via softmax; and the output is the weighted sum of values, projected once more. The causal mask is a single conditional inside the score loop.

```
# tinygpt.py:96-120 — COMPLETE (single-head attention; the mask is one line)
def attention(hidden, W, theta, causal):
    """Single-head attention over the sequence `hidden` (list of d_model vectors)."""
    n = len(hidden)
    d = len(hidden[0])
    q = [rope(matvec(W["Wq"], h), i, theta) for i, h in enumerate(hidden)]
    k = [rope(matvec(W["Wk"], h), i, theta) for i, h in enumerate(hidden)]
    v = [matvec(W["Wv"], h) for h in hidden]
    scale = 1.0 / math.sqrt(d)
    outputs, weights = [], []
    for i in range(n):
        scores = []
        for j in range(n):
            if causal and j > i:
                scores.append(float("-inf"))  # mask the future
            else:
                scores.append(dot(q[i], k[j]) * scale)
        w = softmax(scores)
        weights.append(w)
        ctx = [sum(w[j] * v[j][c] for j in range(n)) for c in range(d)]
        outputs.append(matvec(W["Wo"], ctx))
    return outputs, weights
```

Read the mask: `if causal and j > i`, the score is negative infinity, which softmax turns into exactly zero weight. So position i's output is a weighted sum over positions 0 through i only — the future contributes nothing. The `scale` by one over the square root of the dimension keeps the dot products from growing with dimension and saturating the softmax, exactly as in the attention module. RoPE is applied to q and k before the dot product, so the score carries relative position. Everything else is the query-key-value dance you already know; the mask is the one line that makes it a decoder.

### The full pass: residual stream in, logits out

Now assemble it. The forward function is the pipeline: embed, attention, residual-and-norm, MLP, residual-and-norm, unembed.

```
# tinygpt.py:125-142 — COMPLETE (the whole forward pass)
def forward(data, tokens, causal=True):
    """Embed -> attention (+residual, norm) -> MLP (+residual, norm) -> logits per position."""
    W = data
    E = data["E"]
    theta = data["theta"]

    hidden = [list(E[t]) for t in tokens]                      # token embeddings
    attn_out, weights = attention(hidden, W, theta, causal)
    hidden = [layernorm(add(hidden[i], attn_out[i])) for i in range(len(tokens))]  # residual + norm

    mlp = []
    for h in hidden:
        a = relu(vecmat(h, W["W1"]))       # D -> F, relu
        mlp.append(vecmat(a, W["W2"]))     # F -> D
    hidden = [layernorm(add(hidden[i], mlp[i])) for i in range(len(tokens))]       # residual + norm

    logits = [[dot(h, E[t]) for t in range(len(E))] for h in hidden]  # weight-tied unembed
    return logits, weights
```

Trace the residual stream. `hidden` starts as the token embeddings — one vector per position. Attention produces an output per position, and the `add(hidden[i], attn_out[i])` is the residual connection: the attention result is added to, not substituted for, the input, so the original token information survives and attention only edits it. LayerNorm re-standardizes. The MLP transforms each position on its own — no mixing between positions, unlike attention — and its output is again added residually and normed. Finally the unembedding: each position's vector is dotted with every token's embedding (weight tying reuses `E`) to produce a logit per vocabulary word. The last position's logits, softmaxed, are the next-token distribution from the cold open.

### The mask, proven: attention weights

Now the module's real subject. First, why the last position looks the same masked or not.

```
# $ python3 tinygpt.py --attn
#   positions:      the    cat    sat    on
#   causal   (last): 0.26   0.24   0.25   0.25
#   unmasked (last): 0.26   0.24   0.25   0.25
```

run: 2026-08-26 · deterministic · `python3 tinygpt.py --attn`

The last position is identical either way, and that is the trap in testing this: the final token has no future to mask, so masked and unmasked agree there. The difference lives at earlier positions, where the future exists to be leaked. To see the bug you must look at a position that is not last — which is exactly what a naive test, checking only the final prediction, never does.

### The mask, proven: the causality invariance

Here is the definitive test. A causal model's prediction at position i must depend only on tokens 0 through i, so it cannot change when you append later tokens. Compute the logits at position 1 two ways: from the truncated prefix `the/cat`, and from the full sequence `the/cat/sat/on`.

```
# $ python3 tinygpt.py --peek
#   causal   logits at pos 1, prefix vs full: [-0.909, 0.944, 1.262, ...]  vs  [-0.909, 0.944, 1.262, ...]
#   unmasked logits at pos 1, prefix vs full: [-0.909, 0.944, 1.262, ...]  vs  [-0.773, 0.94, 1.124, ...]
```

run: 2026-08-26 · deterministic · `python3 tinygpt.py --peek`

The test itself is four forward passes — the prefix and the full sequence, each masked and unmasked — comparing the logits at a non-final position:

```
# tinygpt.py:186-193 — COMPLETE (the causality test: prefix vs full, at a non-final position)
    i = 1  # look at the prediction made AT position i (index 1)
    prefix = tokens[: i + 1]                    # the sequence truncated after position i
    full = tokens                               # the full sequence, with future tokens present

    lc_prefix, _ = forward(data, prefix, causal=True)
    lc_full, _ = forward(data, full, causal=True)
    lu_prefix, _ = forward(data, prefix, causal=False)
    lu_full, _ = forward(data, full, causal=False)
```

Read the two rows. With the causal mask, position 1's logits are byte-identical whether the sequence stops at `cat` or continues — the future is invisible, exactly as required. Without the mask, the same logits change: the first component moves from −0.909 to −0.773 when `sat` and `on` are appended, because position 1 attended to them. That change is the model cheating: at training time it would use tokens 2 and 3 to predict the token after position 1, driving its loss down; at generation time those tokens do not exist yet, so the crutch is gone and the predictions collapse. The invariance is the operational definition of causality, and the mask is what enforces it.

### The self-test

The `--check` mode asserts the pass is well-formed and the mask does its job: the distribution normalizes, LayerNorm standardizes, the causal prediction is invariant to future tokens, and the unmasked one is not.

```
# $ python3 tinygpt.py --check
#   next-token distribution sums to 1 = True (1.000000)
#   LayerNorm output has ~0 mean and unit variance = True
#   CAUSAL: position-1 logits unchanged by future tokens = True
#   UNMASKED: position-1 logits change with future tokens (cheating) = True
#   SELF-TEST PASS ...
```

run: 2026-08-26 · deterministic · `python3 tinygpt.py --check`

The two causality assertions are the heart of the check — one demanding invariance with the mask, one demanding its violation without:

```
# tinygpt.py:224-233 — COMPLETE (causal is invariant; unmasked cheats)
    i = 1
    lc_prefix, _ = forward(data, tokens[: i + 1], causal=True)
    lc_full, _ = forward(data, tokens, causal=True)
    causal_invariant = approx_eq(lc_prefix[i], lc_full[i])

    lu_prefix, _ = forward(data, tokens[: i + 1], causal=False)
    lu_full, _ = forward(data, tokens, causal=False)
    unmasked_cheats = not approx_eq(lu_prefix[i], lu_full[i])
```

The `causal_invariant` line is the correctness anchor for the entire architecture: it re-runs the pass on a truncated prefix and the full sequence and demands the position-1 logits match exactly, which can only hold if no future position ever leaked into the computation — through attention, or through any other path. If a refactor accidentally let information flow backward in time, this equality would break before any output looked wrong. The `unmasked_cheats` line is the lesson made adversarial: it requires the mask-less model to actually violate the invariance on this input, proving the mask is load-bearing rather than decorative, and that a test checking only the final token would certify the broken model as correct.

### The running tally

| stage | operation | shape effect |
|---|---|---|
| embed | token id → vector | ids → d_model vectors |
| attention (+residual, norm) | mix across positions, add back, standardize | per-position edit, causal |
| MLP (+residual, norm) | per-position transform, add back, standardize | per-position edit |
| unembed + softmax | project to vocab, normalize | d_model → distribution |

Read the pipeline as two kinds of step. Attention is the only one that moves information between positions, and it is the only one the causal mask governs — every other step is strictly per-position and cannot leak the future even if it tried. That is why the entire causality of a transformer rests on one conditional inside attention: nothing else in the pass crosses positions. Get that one line right and the model is a next-token predictor; get it wrong and everything downstream is trained on answers it will not have, which no amount of scale or training can fix.

### What we did not settle

This is one layer, one head, untrained. Real models stack many layers, so the residual stream passes through the same shape dozens of times, each layer refining it; multiple attention heads run in parallel per layer, each with its own projections, concatenated before the output projection, so different heads specialize. The MLP is usually four times d_model wide, and modern models use gated variants (SwiGLU) rather than plain ReLU. Norm placement varies — pre-norm (normalize before each sublayer) is now standard over the post-norm shown here, for training stability. RoPE here uses a single frequency; real RoPE tiles many. And of course the weights are trained by backpropagation against next-token loss, which is the entire other half of the story this forward pass sets up. What does not change with any of that is the causal mask: every decoder-only model, at every scale, forbids attending to the future, and for exactly the reason proven here.

## Build

The build in one paragraph: implement the forward pass as a pipeline over a residual stream — embed tokens; run attention that projects to query, key, value, applies rotary position, scores with a scaled dot product, masks the future to negative infinity, softmaxes, and mixes values; add the attention output residually and LayerNorm; run a per-position MLP and add it residually and norm; project to logits and softmax; and test causality by the invariance, not the output — the position-i prediction must be identical for a truncated prefix and the full sequence. Only attention crosses positions, so only attention needs the mask.

We opened on the forward pass. The number that proves the architecture is honest is not any logit; it is the invariance:

