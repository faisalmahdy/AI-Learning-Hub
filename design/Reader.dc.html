Why this module
The 16-repo scan reached one verdict above all others: everything in the portfolio measures plumbing, never product. Hash chains are verified, retrieval ranks are benchmarked — but nowhere is there a running script that answers "was the output any good?" This module closes that gap: you reproduce the rubric-eval pattern you already invented, as a mechanized, committed script.
